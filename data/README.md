# Telecom data source

`telecom_churn.csv` is the dataset provided for WGU D601, Scenario 2: Telecommunications Churn. The accompanying scenario and data dictionary describe customer attributes, contracts, service charges and churn. The dashboard analyzes that course dataset; it does not report a live telecom deployment.

The course materials reviewed identify the dataset and scenario but do not state an upstream redistribution license. The repository’s MIT license covers the project code, not a new license grant for third-party data. No claim that the records are synthetic is made.
